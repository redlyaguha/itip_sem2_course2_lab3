# Лабораторная работа 3 — Notification Service (Spring Boot)

## Описание
REST API для управления уведомлениями с поддержкой нескольких каналов доставки (Email, SMS, Push, Telegram).

## Стек
- **Java 17**
- **Spring Boot 4.0.3**
- **Spring WebFlux** — реактивный веб
- **Spring Data JPA** — работа с БД
- **PostgreSQL** — база данных
- **Lombok** — сокращение boilerplate-кода
- **Spring Validation** — валидация данных

## Сущности

### Notification
- ID, заголовок, сообщение, канал (Email/SMS/Push/Telegram), статус, получатель, дата создания

### User
- ID, имя, email, телефон, Telegram ID

## Эндпоинты

### Уведомления (`/notifications`)
| Метод | Путь | Описание |
|-------|------|----------|
| `POST` | `/add` | Создать уведомление |
| `GET` | `/all` | Все уведомления |
| `GET` | `/{id}` | Уведомление по ID |
| `PUT` | `/{id}` | Обновить уведомление |
| `DELETE` | `/{id}` | Удалить уведомление |
| `GET` | `/status/{status}` | Фильтр по статусу |
| `GET` | `/channel/{channel}` | Фильтр по каналу |
| `GET` | `/recipient/{recipientId}` | По получателю |
| `GET` | `/filter` | Фильтр по статусу и каналу |
| `GET` | `/sorted` | Все, сортировка по дате (убыв.) |
| `PATCH` | `/{id}/send` | Отметить как отправленное |

### Пользователи (`/users`)
| Метод | Путь | Описание |
|-------|------|----------|
| `POST` | `/add` | Создать пользователя |
| `GET` | `/all` | Все пользователи |
| `GET` | `/{id}` | По ID |
| `PUT` | `/{id}` | Обновить |
| `DELETE` | `/{id}` | Удалить |

## Запуск

1. Настройте PostgreSQL (порт 5433) и укажите подключения в `.env`
2. Запустите:

```bash
./mvnw spring-boot:run
# или
mvn spring-boot:run
```

## Архитектура
- **controller/** — REST-контроллеры
- **service/** — бизнес-логика (EmailService, SmsService, PushService, TelegramService)
- **repository/** — Spring Data JPA репозитории
- **model/** — JPA-сущности, DTO, enums
- **mapper/** — маппинг Entity ↔ DTO
- **config/** — конфигурация приложения
- **exception/** — обработка исключений

## Проделанная работа
- Разработана полнофункциональная система управления уведомлениями
- Реализован CRUD для уведомлений и пользователей
- Настроена фильтрация по статусу, каналу, получателю
- Реализована сортировка по дате
- Созданы сервисы для разных каналов отправки
- Настроена интеграция с PostgreSQL через JPA
- Использован Lombok для сокращения кода
